Three things to try

  1. Lengthen and add structures. The default chip (4 structures up to 1.5 cm) gives 2.71 ± 0.57 dB/cm. Make the longest waveguide 5 cm and use 8 structures: the error bar shrinks to about ±0.1 dB/cm and the pill reads PRECISE.
  2. Measure only two. Set 2 structures: there is no error bar, and every coupler error goes into the slope. Press "measure a new chip" a few times and watch the answer jump.
  3. Make the couplers identical. Set σ = 0: the fit returns the true loss exactly, and the intercept gives the coupler loss of 4.50 dB, whatever the lengths.
