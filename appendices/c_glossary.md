# Appendix C. Glossary

Acronyms and terms, filled in as the chapters are written.

|---|---|
| BOX | Buried oxide: the SiO₂ layer under the silicon film of an SOI wafer |
| DBR, DFB | Distributed Bragg reflector and distributed-feedback lasers |
| EBL | Electron-beam lithography |
| ER | Extinction ratio |
| FSR | Free spectral range |
| GC | Grating coupler |
| MMI | Multimode-interference coupler |
| MPW | Multi-project wafer run |
| MZI, MZM | Mach–Zehnder interferometer and modulator |
| OMA | Optical modulation amplitude |
| PDK | Process design kit |
| PIC | Photonic integrated circuit |
| SMSR | Side-mode suppression ratio |
| SOA | Semiconductor optical amplifier |
| SOI | Silicon-on-insulator |
| SWG | Subwavelength grating |
| TE, TM | Transverse-electric and transverse-magnetic modes |
| TFLN | Thin-film lithium niobate |
| WDM | Wavelength-division multiplexing |
