# Appendix A. Formula Sheet

The key equations of each chapter on one page, filled in as the chapters are written.
{: .chapterlead }

<p><span class="status status-outline">outline</span></p>

Planned sections: optical power and units; plane waves and Fresnel equations; Gaussian beams and mode overlap; slab and channel waveguides; loss and dispersion; coupled modes and couplers; interferometers and rings; Bragg gratings; grating couplers; thermo-optic and electro-optic tuning; photodetectors and receivers; gain, threshold and rate equations; laser noise and linewidth; link budgets.

A first selection, in the notation used throughout:

| Quantity | Formula |
|---|---|
| Power in dBm | $$P_\mathrm{dBm} = 10\log_{10}(P/1\,\mathrm{mW})$$ |
| Loss conversion | $$\alpha\,[\mathrm{dB/cm}] = 4.343\,\alpha\,[\mathrm{cm^{-1}}]$$ |
| Group index | $$n_g = n_\mathrm{eff} - \lambda\,\mathrm{d}n_\mathrm{eff}/\mathrm{d}\lambda$$ |
| Rayleigh range | $$z_R = \pi w_0^2 n/\lambda$$ |
| Interferometer FSR | $$\mathrm{FSR} = \lambda^2/(n_g \Delta L)$$ |
| Ring FSR | $$\mathrm{FSR} = \lambda^2/(n_g L)$$ |
| Loaded Q | $$Q = \lambda/\Delta\lambda_\mathrm{FWHM}$$ |
| Bragg wavelength | $$\lambda_B = 2 n_\mathrm{eff}\Lambda$$ |
| Grating-coupler phase matching | $$n_\mathrm{eff} - n_c\sin\theta = \lambda/\Lambda$$ |
| Laser threshold | $$\Gamma g_\mathrm{th} = \alpha_i + \tfrac{1}{2L}\ln\tfrac{1}{R_1R_2}$$ |
| FP mode spacing | $$\Delta\lambda = \lambda^2/(2 n_g L)$$ |
| Photodiode responsivity | $$\mathcal{R} = \eta q\lambda/(hc) \approx \eta\,\lambda[\mu\mathrm{m}]/1.24\ \mathrm{A/W}$$ |
